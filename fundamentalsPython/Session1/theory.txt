-> python is a high - level, general purpose programming language known for its simple syntax and readability.
-> it was created by guido van rossum and first released in 1991.

Example : 
         print("Hello world")

-> python lets you write instructions that a computer can execute.
-> it's syntax is designed to be reletively close to human - readable language.

                     key characteristics :-
    1) Easy to learn
    2) High - level

    4) Dynamically typed
    5) Cross - platform

4) Installing Python :

-> The first thing we need is the Python interpreter.

-> Download Python from the official Python website:
   Python.org
-> Windows installation  :
    1) Download the latest stable Python 3 release.
    2) Run the installer
    3) Check "Add Python to PATH".
    4) Click Install Now.
    5) Open Command Prompt.
    6) Verify the installation: python --version

8) Python Code Execution Model:
 
  Understanding how Python executes your code is important.

consider:
   print('A')
   print('B')
   print('C')

Python normally executes these statements from top to bottom.

            Python source code
                   ↓
             Python runtime
                   ↓
                Execute
                   ↓
                Output

 * What happens internally ?

                 hello.py
                     ↓
               Python interpreter
                     ↓
               Python bytecode
                     ↓
         Python Virtual Machine (PVM)
                     ↓
               Program output

9) Interactive Mode vs Script Mode :
 ->Python can be used in two common ways.

 i) Interactive mode: 

 ->   Start Python from the terminal: 
      python

     then type : 
      >>> 2 + 3
       5

   see the immediately result.

   this is used for :
     - learning python 
     - quick calculations

    Exit with :
      Exit()

  ii) script mode:
  ->   Instead of entering code one line at a time, save it in a .py file :

       calculator.py
        
         a = 10 
         b = 20

        print(a + b)

      run :
        output : 
            30
